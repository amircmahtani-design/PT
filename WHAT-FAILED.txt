THE CONCLUSION
--------------
Most of what went wrong was mine, not the model's. Scrapping the brain would
not have prevented a single one of the eighteen above.

BUT YOUR INSTINCT IS STILL RIGHT, for a different reason: anything that
CHANGES STATE should never depend on language. Not because the model is bad,
but because a command either happened or it didn't, and that shouldn't be
probabilistic.

The evidence is already in the app. When I moved "swap X" into code in v88, it
stopped failing. Immediately and permanently.

29 things already run with no model involved: the programme, anchors, load
calls, mastery rule, easy-jump, kit limits, cool-downs, prefill, pattern
coverage, deload detection, alcohol maths. Those have not failed.

So the fix isn't to remove the coach. It's to move the remaining commands into
code, and leave the model doing only what it's actually good at: explaining,
judging, and talking.
